# DNS Tunnel Messenger (پیام‌رسان امن تونل DNS)

یک پیام‌رسان ضدفیلترینگ و مقاوم در برابر خاموشی اینترنت و اینترنت ملی (سفید) که تمامی ترافیک را در قالب بسته‌های استاندارد پروتکل DNS (شبیه به dnstt و MasterDNS) تونل می‌کند.

---

## ویژگی‌های کلیدی

- **تونل کامل بر بستر DNS**: تبادل داده از طریق رکوردهای DNS TXT و ساب‌دومین‌های Base32؛ بدون نیاز به ترافیک مستقیم TCP/UDP غیر از پورت ۵۳.
- **پشتیبانی از چندین DNS Resolver همزمان**: خواندن رسیورها از فایل اختصاصی `resolvers.txt` (با فرمت `IP:53` یا `IP`)، همراه با چرخش خودکار (Failover)، ارسال موازی (Race Mode) و بنچمارک بلادرنگ سریع‌ترین رسیورها.
- **همزیستی بدون تداخل با MasterDNS**: قابلیت اجرا روی پورت مجزا (مثل ۵۳۵۴) یا مدیریت پورت ۵۳ همراه با فوروارد شفاف کوئری‌های خارج از محدوده به MasterDNS (`127.0.0.1:53`).
- **رمزنگاری سرتاسری (Zero-Knowledge E2EE)**: رمزنگاری تمام پیام‌ها و فایل‌ها با الگوریتم **AES-256-GCM** و مشتق‌سازی کلید با PBKDF2. سرور صرفاً تگ‌های تصادفی ۱۶ کاراکتری هگز و دیتای انکریپت‌شده را ذخیره می‌کند و هیچ دسترسی به محتوا، نام کانال یا هویت کاربران ندارد.
- **معماری مبتنی بر کانال و گفتگوی مستقیم**: بدون وجود گروه سنتی؛ هر فرد با داشتن کلید AES کانال می‌تواند پیام‌ها را رمزگشایی و مشاهده کند.
- **انتقال فایل امن**: پشتیبانی از ارسال فایل، تصویر و اسناد با تکه‌تکه کردن بسته‌ها (Chunking) و قابلیت تنظیم سقف حجم (پیش‌فرض حداکثر ۲۰ مگابایت).
- **ردیاب خودکار تلگرام با Kurigram**: ماژول سلف‌بات برای رصد بلادرنگ کانال‌های مشخص تلگرام و فوروارد خودکار پست‌ها به کانال‌های پیام‌رسان با کلید اختصاصی.
- **رابط وب پیشرفته (Web GUI)**: طراحی واکنش‌گرا و سبک با پوسته تاریک و پشتیبانی کامل از زبان فارسی و راست‌چین.

## راه‌اندازی سریع سرور (Ubuntu)

یک اسکریپت خودکار برای نصب پیش‌نیازها، تنظیم سرویس systemd و باز کردن فایروال آماده شده است:

```bash
git clone https://github.com/your-username/dns-messenger.git
cd dns-messenger
chmod +x install_ubuntu.sh
sudo ./install_ubuntu.sh
```

اسکریپت به صورت تعاملی اطلاعات زیر را دریافت می‌کند:
1. دامنه پایه تونل (مانند `msg.yourdomain.com`)
2. پورت لیسن سرور (پیش‌فرض `5354` در صورت همزیستی با MasterDNS یا `53`)
3. آدرس سرور Upstream برای فوروارد ترافیک MasterDNS (مانند `127.0.0.1:53`)

### مدیریت سرویس سرور در اوبونتو:
```bash
sudo systemctl status dns-messenger
sudo journalctl -u dns-messenger -f
sudo systemctl restart dns-messenger
```

## تنظیمات DNS در کلودفلر یا رجیسترار دامنه

برای اتصال صحیح کلاینت‌ها به سرور، دو رکورد زیر را در پنل کلودفلر (با ابر خاموش / DNS Only) یا پنل دامنه خود بسازید:

1. **A Record**:
   - نام (Name): `ns1.msg.yourdomain.com`
   - مقدار (IPv4): آدرس IP سرور شما (مثلاً `198.51.100.1`)
   - وضعیت پروکسی: **DNS Only** (خاکستری)

2. **NS Record**:
   - نام (Name): `msg.yourdomain.com`
   - مقدار (Nameserver): `ns1.msg.yourdomain.com`

## راه‌اندازی کلاینت و رابط کاربری وب

### ۱. نصب وابستگی‌ها:
```bash
pip install -r requirements.txt
```

### ۲. اجرای کلاینت و پنل وب:
```bash
python run.py client
```
پس از اجرا، مرورگر خود را باز کرده و به آدرس زیر بروید:
```
http://127.0.0.1:8080
```

### ۳. اجرای سرور به صورت مستقل:
```bash
python run.py server
```

### ۴. اجرای همزمان هر دو روی یک سیستم (جهت آزمایش و تست):
```bash
python run.py both
```

## مدیریت فایل `resolvers.txt`

فایل `resolvers.txt` در ریشه پروژه قرار دارد و لیست سرورهای DNS واسط را مشخص می‌کند. ساختار آن به شرح زیر است:

```text
# لیست Resolverهای عمومی
1.1.1.1:53
8.8.8.8:53
9.9.9.9:53
77.88.8.8:53

# Resolverهای شبکه ملی (جهت کارکرد در زمان قطعی کامل اینترنت بین‌الملل)
10.202.10.202:53
10.202.10.102:53
5.200.200.200:53
```

- از طریق منوی **تنظیمات** در رابط وب می‌توانید محتوای این فایل را ویرایش کرده یا با فشردن دکمه **تست سرعت و رتبه‌بندی**، رسیورها را بر اساس پینگ و پاسخ‌دهی مرتب‌سازی کنید.

## تنظیمات ردیاب کانال‌های تلگرام (Kurigram Self-Bot)

در منوی **تنظیمات** رابط وب یا در فایل `data/config.json`:

```json
{
  "kurigram_tracker": {
    "enabled": true,
    "api_id": 1234567,
    "api_hash": "abcdef0123456789abcdef",
    "session_string": "",
    "channels_map": [
      {
        "tg_channel": "@target_telegram_channel",
        "messenger_channel": "news",
        "password": "AES_SECRET_PASSWORD"
      }
    ]
  }
}
```

پست‌های منتشرشده در کانال‌های مشخص‌شده به صورت خودکار با کلید AES تعیین‌شده رمزگذاری شده و روی کانال مورد نظر در تونل DNS منتشر می‌شوند.
