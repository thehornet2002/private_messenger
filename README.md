# DNS Tunnel Messenger (پیام‌رسان امن تونل DNS)

یک پیام‌رسان ضدفیلترینگ و مقاوم در برابر خاموشی اینترنت و اینترنت ملی (سفید) که تمامی ترافیک را در قالب بسته‌های استاندارد پروتکل DNS (شبیه به dnstt و MasterDNS) تونل می‌کند.

---

## معماری و ویژگی‌های کلیدی

- **تونل کامل بر بستر DNS**: تبادل داده از طریق رکوردهای DNS TXT و ساب‌دومین‌های Base32؛ بدون نیاز به ترافیک مستقیم TCP/UDP غیر از پورت ۵۳.
- **ذخیره‌سازی پایدار روی دیسک با سقف ۱۰۰ پیام اخیر (100-Message Channel History)**:
  - پیام‌ها، تصاویر، ویدیوها و فایل‌ها روی دیسک سرور (`data/server_storage.db`) ذخیره می‌شوند.
  - برای هر کانال همیشه ۱۰۰ پیام آخر نگهداری شده و پیام‌ها و فایل‌های قدیمی‌تر به طور خودکار پاک‌سازی می‌شوند.
  - کلاینت‌ها با ورود به هر کانال، تاریخچه ۱۰۰ پیام گذشته را به صورت خودکار دریافت می‌کنند.
- **کشف و دریافت خودکار کانال‌های عمومی از سرور (Public Channels Auto-Discovery)**:
  - با ورود به برنامه یا فشردن دکمه «📡 دریافت کانال‌های عمومی»، لیست تمام کانال‌های رصدشده از طریق DNS از سرور استعلام شده و به سایدبار کلاینت افزوده می‌شود.
- **دانلود انتخابی رسانه (Auto-Download OFF)**:
  - برای حفظ پهنای باند و سرعت بالای پروتکل DNS، متن پیام‌ها بلادرنگ دانلود شده و فایل‌ها/تصاویر/ویدیوها تنها با کلیک مستقیم کاربر دانلود و نمایش داده می‌شوند.
- **پنل مدیریت اختصاصی سرور (Server Web Admin Dashboard)**:
  - داشبورد نظارت بلادرنگ روی پورت `8081` (نمایش تعداد کوئری‌ها، ترافیک، پیام‌های ذخیره‌شده روی دیسک).
  - راه‌انداز مرحله‌به‌مرحله سلف‌بات تلگرام (Kurigram) با پشتیبانی کامل از **کد پیامک و رمز دو مرحله‌ای (2FA)**.
  - مدیریت کانال‌های تلگرام جهت بازنشر مستقیم و خودکار در تونل DNS.
- **کانال‌های عمومی و همگانی تلگرام**:
  - سلف‌بات تلگرام فقط روی سرور (دارای اینترنت آزاد) اجرا می‌شود.
  - کانال‌های عمومی تلگرام بدون نیاز به رمزنگاری و بدون پسورد برای تمام کلاینت‌ها پخش می‌شوند.
- **گفتگوهای گروهی و محرمانه با رمزنگاری AES-256-GCM**:
  - هر دو یا چند کلاینت با وارد کردن یک رمز مشترک، وارد یک گروه امن می‌شوند و تمام پیام‌ها و فایل‌ها با کلید اختصاصی آن‌ها رمزگذاری سرتاسری می‌شود.
- **پشتیبانی از چندین DNS Resolver همزمان**:
  - بارگذاری لیست رسیورها از فایل اختصاصی `resolvers.txt` (با فرمت `IP:53` یا `IP`).
  - چرخش هوشمند، ارسال مسابقه‌ای (Race Mode) در شرایط افت کیفیت شبکه و بنچمارک بلادرنگ پینگ رسیورها.
- **همزیستی بدون تداخل با MasterDNS**:
  - امکان اجرا روی پورت مجزا (مثل ۵۳۵۴) یا پورت ۵۳ همراه با فوروارد شفاف کوئری‌های خارج از محدوده به MasterDNS (`127.0.0.1:53`).
- **انتقال فایل با کنترل حجم**:
  - قطعه‌بندی خودکار فایل‌ها در قالب پکت‌های DNS با قابلیت تنظیم سقف مجاز (پیش‌فرض ۲۰ مگابایت).
- **رابط وب اختصاصی کلاینت (Client Web GUI)**:
  - پنل چت سبک و سریع روی پورت `8080` با طراحی تاریک و پشتیبانی کامل از زبان فارسی و راست‌چین.

## ساختار فایل‌های پروژه

```text
private_messenger/
├── dns_messenger/
│   ├── client.py             # هسته کلاینت تونل DNS و رمزگشایی
│   ├── config.py             # مدیریت تنظیمات و بارگذاری رسیورها
│   ├── crypto.py             # رمزنگاری AES-256-GCM، مشتق‌سازی PBKDF2 و حالت Public
│   ├── dns_proto.py          # سریال‌سازی بسته‌های باینری و کدگذاری دامنه‌ها
│   ├── server.py             # سرور معتبر DNS با حافظه موقت RAM
│   ├── server_admin_ui.py    # پنل وب مدیریت سرور و لاگین سلف‌بات تلگرام (پورت 8081)
│   ├── telegram_server_bot.py# سلف‌بات تلگرام سمت سرور (Kurigram با پشتیبانی از 2FA)
│   └── web_ui.py             # پنل کاربری کلاینت پیام‌رسان (پورت 8080)
├── install_ubuntu.sh         # اسکریپت نصب خودکار روی سرور اوبونتو
├── requirements.txt          # کتابخانه‌های پایتون
├── resolvers.txt             # لیست رسیورهای DNS واسط
├── run.py                    # نقطه ورود اصلی برای اجرا (server / client / both)
└── test_all.py               # مجموعه آزمون‌های جامع اعتبارسنجی
```

## راه‌اندازی سرور (Ubuntu 20.04 / 22.04 / 24.04)

یک اسکریپت خودکار برای نصب وابستگی‌ها، مدیریت پورت ۵۳ و تنظیم سرویس systemd آماده است:

```bash
git clone https://github.com/thehornet2002/private_messenger.git
cd private_messenger
chmod +x install_ubuntu.sh
sudo ./install_ubuntu.sh
```

در طول نصب، اطلاعات زیر درخواست می‌شود:
1. **Base Domain:** دامنه پایه تونل (مثلاً `msg.example.com`)
2. **Listen Port:** پورت سرور (پیش‌فرض ۵۳ یا ۵۳۵۴ برای همزیستی با MasterDNS)
3. **Forward Upstream:** آدرس DNS سرور اصلی برای فوروارد کوئری‌های عادی (مثلاً `127.0.0.1:53` یا `8.8.8.8:53`)

### دسترسی به پنل مدیریت سرور:
پس از نصب، در مرورگر آدرس زیر را باز کنید:
```
http://SERVER_IP:8081
```
از این پنل می‌توانید:
- وضعیت پردازش بسته‌ها و پیام‌ها را به صورت زنده مشاهده کنید.
- با وارد کردن شماره تماس، کد پیامک و رمز ۲FA به اکانت تلگرام متصل شوید.
- کانال‌های تلگرام دلخواه را برای بازنشر همگانی در پیام‌رسان تنظیم کنید.

---

## تنظیم رکوردهای DNS در کلودفلر یا دامنه

دو رکورد زیر را در پنل DNS خود ثبت کنید:

1. **رکورد نوع A (آدرس سرور):**
   - **Name:** `ns1.msg` (یا نام کامل `ns1.msg.example.com`)
   - **IPv4:** آدرس آی‌پی سرور
   - **Proxy:** حتماً **DNS Only** (خاکستری)

2. **رکورد نوع NS (نمایندگی ساب‌دومین):**
   - **Name:** `msg` (یا `msg.example.com`)
   - **Nameserver:** `ns1.msg.example.com`

## راه‌اندازی پیام‌رسان در سمت کلاینت (کاربر)

### ۱. نصب نیازمندی‌ها:
```bash
pip install -r requirements.txt
```

### ۲. اجرای کلاینت و پنل چت:
```bash
python run.py client
```

سپس در مرورگر وارد شوید:
```
http://127.0.0.1:8080
```

### ۳. نحوه استفاده:
- **کانال‌های همگانی تلگرام:** روی «➕ ایجاد یا عضویت» کلیک کنید، نام کانال را وارد کنید و کادر رمز عبور را خالی بگذارید.
- **گروه یا چت خصوصی:** نام گروه را وارد کنید و یک رمز عبور به اشتراک بگذارید؛ تمام افرادی که این رمز را وارد کنند پیام‌های یکدیگر را دریافت و رمزگشایی می‌کنند.

## مدیریت فایل `resolvers.txt`

فایل `resolvers.txt` حاوی آدرس رسیورهای DNS با فرمت `IP:PORT` یا `IP` است:
```text
1.1.1.1:53
8.8.8.8:53
9.9.9.9:53
10.202.10.202:53
```
در پنل کلاینت با کلیک روی **تست سرعت و رتبه‌بندی**، رسیورها تست شده و سریع‌ترین رسیور به صورت خودکار انتخاب می‌شود.
